# Maestro

**M**ulti-**A**gent **E**xecution & **S**ession **T**erminal **R**untime **O**rchestrator

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/toki-voki/maestro/main/distribution/install.sh | sh
```

Or `brew install toki-voki/tap/maestro` · `go install github.com/toki-voki/maestro@latest` · [releases](https://github.com/toki-voki/maestro/releases) for deb/rpm/apk and Windows. Check with `maestro version`.

## Develop

`make help` lists targets; `make check` runs what CI runs. Product requirements, build, release and distribution: [docs/development/PRD.md](docs/development/PRD.md).
